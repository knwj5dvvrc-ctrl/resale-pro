# ReSale Pro v4.0 — 無料の仕入れおすすめ度分析

前バージョンの在庫・セット分析・相場記録・利益計算に加え、相場分析画面に100点満点の仕入れおすすめ度を追加しました。

- 目標利益達成: 最大40点
- 売却価格サンプル数: 最大25点（5件で満点）
- 価格のばらつき: 最大20点
- 仕入れ利益率: 最大15点

**重要**: スコアは入力データに基づく独自の数式評価であり、生成AIによる価格予測やメルカリの自動収集ではありません。メルカリ検索リンクから売却済み相場を確認し、価格を登録してください。実際の成約価格、売却速度、送料、商品状態で結果は変わります。

GitHub Pages: ZIPを展開し、ファイルをリポジトリのルートに配置してください。旧データは同一ドメイン・同一パスのlocalStorageに保存されている限り引き継がれます。更新前に在庫・セット・相場データを個別にバックアップしてください。
